# spartab-site

Website for FRC Team 2976, the Spartabots (Skyline High School, Sammamish WA).

Plain HTML/CSS, no build step. Open `index.html` or run any static server:

    python -m http.server

Pages: index, robots, history, sponsors, join. Header and footer are copy-pasted
into each page, so if you change one, change all five.

Photos in `img/` are from the team's old site (SkylineSpartabots/SpartaSite),
resized to keep the repo small. Keep new ones under ~400 KB.
